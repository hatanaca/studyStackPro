# Revisão de Segurança e Código — 2026-06-25

## Escopo

Revisão completa do repositório StudyTrackPro cobrindo: Laravel backend, Vue 3 frontend, Docker/infraestrutura, variáveis de ambiente e configuração.

---

## CRÍTICO

### 1. Secrets reais commitados em `backend/.env.example`
- **Arquivo**: `backend/.env.example:77-97`
- **Problema**: Google Client Secret, Discord Client Secret e YouTube API Key estão com valores reais.
- **Status**: CORRIGIDO — substituídos por placeholders.
- **Ação adicional**: Rotacionar todos os secrets expostos no Google Cloud Console, Discord Developer Portal e Google API Console.

### 2. `Socialite::stateless()` desativa proteção CSRF no OAuth
- **Arquivo**: `backend/app/Http/Controllers/V1/OAuthController.php:31,64`
- **Problema**: `->stateless()` desabilita a verificação do parâmetro `state`, permitindo ataques CSRF no fluxo OAuth.
- **Status**: CORRIGIDO — removido `->stateless()` de ambos os métodos.

### 3. User model `$fillable` inclui tokens OAuth
- **Arquivo**: `backend/app/Models/User.php:28-43`
- **Problema**: `discord_token`, `google_token` e refresh tokens estão em `$fillable`, permitindo mass assignment acidental.
- **Status**: CORRIGIDO — tokens OAuth removidos de `$fillable`.

### 4. CSS injection via `fontSans` sem sanitização
- **Arquivo**: `frontend/src/stores/ui.store.ts:83-94`
- **Problema**: Valor do input do usuário é escrito diretamente em `document.documentElement.style.setProperty()` sem sanitização.
- **Status**: CORRIGIDO — adicionada whitelist de fontes.

### 5. Senhas hardcoded com fallback em `docker-compose.yml`
- **Arquivo**: `docker-compose.yml` (múltiplas linhas)
- **Problema**: `REDIS_PASSWORD:-<REMOVED>` e `DB_PASSWORD:-secret` como defaults.
- **Status**: CORRIGIDO — fallbacks removidos, uso de `${VAR:?msg}` no compose.

### 6. `frontend/.env` com valor commitado
- **Arquivo**: `frontend/.env:14`
- **Problema**: `VITE_REVERB_APP_KEY=local-key` commitado (embora o `.env` não seja rastreado pelo git).
- **Status**: OK — `.env` não está no git (verificado via `git ls-files`).
