# Security and Code Review — 2026-06-25

## Scope

Complete review of the StudyTrackPro repository covering: Laravel backend, Vue 3 frontend, Docker/infrastructure, environment variables, and configuration.

---

## CRITICAL

### 1. Real secrets committed in `backend/.env.example`
- **File**: `backend/.env.example:77-97`
- **Issue**: Google Client Secret, Discord Client Secret, and YouTube API Key contain real values.
- **Status**: FIXED — replaced with placeholders.
- **Additional action**: Rotate all exposed secrets in Google Cloud Console, Discord Developer Portal, and Google API Console.

### 2. `Socialite::stateless()` disables CSRF protection in OAuth
- **File**: `backend/app/Http/Controllers/V1/OAuthController.php:31,64`
- **Issue**: `->stateless()` disables `state` parameter verification, allowing CSRF attacks in the OAuth flow.
- **Status**: FIXED — removed `->stateless()` from both methods.

### 3. User model `$fillable` includes OAuth tokens
- **File**: `backend/app/Models/User.php:28-43`
- **Issue**: `discord_token`, `google_token`, and refresh tokens are in `$fillable`, allowing accidental mass assignment.
- **Status**: FIXED — OAuth tokens removed from `$fillable`.

### 4. CSS injection via `fontSans` without sanitization
- **File**: `frontend/src/stores/ui.store.ts:83-94`
- **Issue**: User input value is written directly to `document.documentElement.style.setProperty()` without sanitization.
- **Status**: FIXED — added font whitelist.

### 5. Hardcoded passwords with fallback in `docker-compose.yml`
- **File**: `docker-compose.yml` (multiple lines)
- **Issue**: `REDIS_PASSWORD:-<REMOVED>` and `DB_PASSWORD:-secret` as defaults.
- **Status**: FIXED — fallbacks removed, using `${VAR:?msg}` in compose.

### 6. `frontend/.env` with committed value
- **File**: `frontend/.env:14`
- **Issue**: `VITE_REVERB_APP_KEY=local-key` committed (although `.env` is not tracked by git).
- **Status**: OK — `.env` is not in git (verified via `git ls-files`).

## Best Practices Found

- Health checks on all Docker services
- Resource limits (CPU/memory) defined
- Server tokens hidden in nginx
- Lua-based WAF configured
- PHP runs as www-data
- Volumes with `:ro` where possible
- Redis with password authentication
- `unless-stopped` restart policies
- Internal network isolation
