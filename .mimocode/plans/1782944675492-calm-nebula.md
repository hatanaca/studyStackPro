# Merge 5 branches de GitHub Actions

## Branches a mergear
1. `dependabot/github_actions/actions/checkout-7` — actions/checkout 4 → 7
2. `dependabot/github_actions/actions/upload-artifact-7` — actions/upload-artifact 4 → 7
3. `dependabot/github_actions/docker/build-push-action-7` — docker/build-push-action 5 → 7
4. `dependabot/github_actions/docker/login-action-4` — docker/login-action 3 → 4
5. `dependabot/github_actions/docker/setup-buildx-action-4` — docker/setup-buildx-action 3 → 4

## Estratégia
Mergear cada branch em `main` via `gh pr merge` direto (sem PRs, já que somos o único colaborador).

## Passos

1. `git checkout main && git pull origin main`
2. Para cada branch:
   - `git merge origin/<branch>` (ou criar PR + merge com --admin)
   - `git push origin main`
3. Verificar que workflows continuam funcionando

## Arquivos afetados
- `.github/workflows/backend-ci.yml`
- `.github/workflows/frontend-ci.yml`
- `.github/workflows/deploy.yml`

## Verificação
- Checar `gh run list` após merge para confirmar que CI roda sem erro
