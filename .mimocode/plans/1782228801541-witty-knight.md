# Plano: Chat Discord (leitura)

> Chat read-only que mostra mensagens dos canais Discord do usuário logado.

## Escopo

- **Leitura** de guilds, canais e mensagens via token OAuth do usuário
- **Sem envio** de mensagens
- Backend proxy para Discord API + Frontend com UI de chat

---

## Backend

### 1. DiscordService

**Arquivo:** `backend/app/Services/DiscordService.php`

Serviço que usa `discord_token` do usuário para chamar a Discord API.

```php
class DiscordService
{
    public function getGuilds(User $user): array
    // GET https://discord.com/api/v10/users/@me/guilds

    public function getChannels(User $user, string $guildId): array
    // GET https://discord.com/api/v10/guilds/{guildId}/channels

    public function getMessages(User $user, string $channelId, int $limit = 50, ?string $before = null): array
    // GET https://discord.com/api/v10/channels/{channelId}/messages?limit=X&before=Y

    private function request(User $user, string $method, string $url, array $params = []): mixed
    // Helper que usa Http::withToken($user->discord_token)
    // Trata 401 (token expirado) com refresh
}
```

### 2. Token Refresh

**Arquivo:** `backend/app/Services/DiscordTokenService.php`

Refreshing Discord tokens requires the user to re-authorize — Discord doesn't support refresh tokens like Google. When the token expires, we detect the 401 and return an error indicating re-authorization is needed.

```php
class DiscordTokenService
{
    public function isTokenExpired(User $user): bool
    // Compara discord_token_expires_at com now()

    public function handleExpiredToken(User $user): ?string
    // Retorna URL de re-autorização ou null se válido
}
```

### 3. Controller

**Arquivo:** `backend/app/Http/Controllers/V1/DiscordController.php`

```php
class DiscordController extends Controller
{
    use HasApiResponse;

    public function __construct(
        private DiscordService $discord,
        private DiscordTokenService $tokenService,
    ) {}

    public function guilds(Request $request): JsonResponse
    // GET /discord/guilds — lista guilds do usuário

    public function channels(Request $request, string $guildId): JsonResponse
    // GET /discord/guilds/{guildId}/channels — lista canais de texto

    public function messages(Request $request, string $channelId): JsonResponse
    // GET /discord/channels/{channelId}/messages
    // Query params: ?limit=50&before=<message_id> (paginação)

    public function me(Request $request): JsonResponse
    // GET /discord/me — informações do usuário Discord
}
```

### 4. Rotas

**Arquivo:** `backend/routes/api.php` (adicionar dentro do grupo auth:sanctum)

```php
Route::prefix('discord')->name('discord.')->group(function () {
    Route::middleware('throttle:30,1')->group(function () {
        Route::get('me', [DiscordController::class, 'me']);
        Route::get('guilds', [DiscordController::class, 'guilds']);
        Route::get('guilds/{guildId}/channels', [DiscordController::class, 'channels']);
        Route::get('channels/{channelId}/messages', [DiscordController::class, 'messages']);
    });
});
```

## Frontend

export interface DiscordGuild {

### 8. API Module

**Arquivo:** `frontend/src/api/modules/discord.api.ts`

```typescript
import { apiClient } from '@/api/client'
import { ENDPOINTS } from '@/api/endpoints'

export const discordApi = {
  me: () => apiClient.get(ENDPOINTS.discord.me),
  guilds: () => apiClient.get(ENDPOINTS.discord.guilds),
  channels: (guildId: string) => apiClient.get(ENDPOINTS.discord.channels(guildId)),
  messages: (channelId: string, params?: { limit?: number; before?: string }) =>
    apiClient.get(ENDPOINTS.discord.messages(channelId), { params }),
}
```
