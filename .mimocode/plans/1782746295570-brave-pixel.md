# Rodada Final — Correções de Design Restantes

## Contexto
Duas rodadas de correções já foram aplicadas (~60 arquivos). Uma varredura final identificou inconsistências residuais.

## Correções Planejadas

### 1. Cores hardcoded em CSS de componentes (6 arquivos)
Substituir hex por `var(--color-*)` onde possível:

- **TechDistributionPanel.vue** — gradient `#8b5cf6/#7c3aed` → `var(--color-primary)/var(--color-primary-hover)`, `#fff` → `var(--color-text)`
- **GraficosToolbar.vue** — focus border `#8b5cf6` → `var(--color-primary)`
- **CanvasSidebar.vue** — default `#000000` → `#fafafa` (texto claro para dark mode)
- **canvas.store.ts** — default `#000000` → `#fafafa`
- **TechnologyCard.vue** — `color-mix(..., #000)` → `color-mix(..., #09090b)`
- **useApexChartTheme.ts** — centralizar fallbacks como constantes no topo do arquivo (mantém hardcoded pois roda em JS antes do CSS, mas organiza)

**Nota:** Cores em JS arrays (chart palette `['#8b5cf6', ...]`) não podem usar CSS vars — aceitável manter.

### 2. Border-radius px → tokens (6 arquivos, ~12 ocorrências)
- TechDistributionPanel: `10px` → `var(--radius-lg)`, `8px` → `var(--radius-md)`
- KpiStrip: `16px` → `var(--radius-xl)`
- GraficosToolbar: `16px` → `var(--radius-xl)`, `10px` → `var(--radius-lg)`, `8px` → `var(--radius-md)`
- ChartPanel: `16px` → `var(--radius-xl)`
- GraficosView: `999px` → `var(--radius-full)`
- TechDistributionWidget: `999px` → `var(--radius-full)`

**Exceções aceitáveis:** `2px` em legendas Heatmap, `50%` em MiniPlayer, `6px`/`22px` em StudyPathFlow (formas custom).

### 3. Duplicação de utilitários (3 arquivos)
- Substituir `.toISOString().slice(0, 10)` por `toISODateString()` em:
  - GoalForm.vue:39
  - useGraficos.ts:13-14
  - GraficosToolbar.vue:27-28
- Remover `isValidHexColor` de validators.ts (duplicata de `isHexColor` em validators.extended.ts)

### 4. Último font-size px (1 arquivo)
- GraficosView.vue:510 — `font-size: 14px` → `font-size: var(--text-sm)`
