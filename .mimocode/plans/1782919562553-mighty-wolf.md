# Fix: CI Backend falhando no step "Copy env"

## Problema

O step "Copy env" no `backend-ci.yml` roda `php artisan key:generate` sem variaveis de ambiente de banco. O Laravel tenta conectar no PostgreSQL durante o boot e falha.

## Solucao

Separar o step "Copy env" em dois steps:

1. **Copy env** — apenas `cp .env.example .env`
2. **Generate app key** — `php artisan key:generate` com env vars do CI (`DB_HOST=127.0.0.1`, etc.)

## Arquivo alterado

- `.github/workflows/backend-ci.yml` — linha 53-55

## Mudanca

De:
```yaml
- name: Copy env
  working-directory: backend
  run: mkdir -p bootstrap/cache && cp .env.example .env && php artisan key:generate
```

Para:
```yaml
- name: Copy env
  working-directory: backend
  run: cp .env.example .env

- name: Generate app key
  working-directory: backend
  run: php artisan key:generate
  env:
    DB_CONNECTION: pgsql
    DB_HOST: 127.0.0.1
    DB_PORT: 5432
    DB_DATABASE: studytrack_test
    DB_USERNAME: postgres
    DB_PASSWORD: ${{ secrets.CI_DB_PASSWORD }}
```
