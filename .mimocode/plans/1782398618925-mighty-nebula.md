# Plano: Corrigir feature /canva

## Problema Identificado

O build TypeScript falha impedindo todo o frontend de funcionar:

```
error TS2688: Cannot find type definition file for 'youtube'.
  The file is in the program because:
    Entry point of type library 'youtube' specified in compilerOptions
```

**Causa raiz**: `tsconfig.json` linha 15 referencia `"youtube"` no array `types`, mas não existe `@types/youtube` instalado nem definição de tipo customizada.

## Código Afetado

- `frontend/tsconfig.json:15` — `"types": ["vite/client", "vitest/globals", "youtube"]`

## Solução

Remover `"youtube"` do array `types` em `tsconfig.json`. O código usa a API YouTube via endpoints backend (não carrega o player JS do YouTube diretamente), então não precisa de tipos globais `YT`.

## Verificação

1. `npm run build` deve completar sem erros TypeScript
2. Navegar para `/canva` e verificar que o canvas Fabric.js carrega
3. Testar ferramentas: selecionar, desenhar, adicionar formas/texto
