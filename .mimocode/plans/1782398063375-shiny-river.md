# Plano: Feature de Desenho/Edição de Imagens

## Visão Geral

**Objetivo:** Adicionar uma rota/feature completa de desenho e edição de imagens no StudyTrack Pro, combinando: whiteboard, editor de imagens, anotações e diagramas.

**Lib escolhida:** [Fabric.js](https://github.com/fabricjs/fabric.js) (31.3k stars, MIT License)

**Por que Fabric.js:**
- Framework-agnóstico (funciona perfeitamente com Vue 3)
- Suporta: desenho livre, formas, texto, imagens, filtros, SVG
- Sem restrições de licença para produção
- leve (~200KB), sem dependências externas
- TypeScript nativo

---

## Funcionalidades

| Categoria | Ferramentas |
|-----------|-------------|
| **Desenho** | Pincel livre, pincel de textoura, borracha, linha |
| **Formas** | Retângulo, círculo, triângulo, seta, estrela, linha |
| **Texto** | Texto livre, textbox editável, fonte/tamanho/cor |
| **Imagens** | Upload de imagem, arrastar, redimensionar, rotacionar |
| **Filtros** | Brilho, contraste, saturação, grayscale, blur |
| **Anotações** | Highlight semi-transparente, seta de comentário, sticky note |
| **Diagramas** | Conexões entre formas, snap-to-grid, alinhamento |
| **Export** | PNG, JPEG, SVG, JSON (para salvar/carregar) |

### 3. useCanvas.ts (Composable Principal)

```typescript
import { Canvas } from 'fabric'

export function useCanvas(canvasRef: Ref<HTMLCanvasElement>) {
  let canvas: Canvas | null = null

  function initCanvas() {
    canvas = new Canvas(canvasRef.value, {
      width: window.innerWidth - 280,
      height: window.innerHeight - 64,
      backgroundColor: '#ffffff',
      selection: true,
    })
  }

  // Tools
  function setTool(tool: string) { ... }
  function addShape(type: string) { ... }
  function addImage(url: string) { ... }
  function addText(text: string) { ... }
  function applyFilter(filter: string) { ... }

  // History
  function undo() { ... }
  function redo() { ... }

  // Export
  function toJSON() { ... }
  function toPNG() { ... }
  function toSVG() { ... }

  return { canvas, initCanvas, setTool, addShape, addImage, ... }
}
```

### 4. Canvas Store (Pinia)

```typescript
export const useCanvasStore = defineStore('canvas', () => {
  const activeTool = ref('select')
  const canUndo = ref(false)
  const canRedo = ref(false)
  const zoom = ref(100)
  const selectedObject = ref(null)

  return { activeTool, canUndo, canRedo, zoom, selectedObject }
})
```

- Retângulo, Círculo, Triângulo

- Texto livre (clique e digite)

- Upload de imagem (drag & drop ou botão)
- Redimensionar, rotacionar, espelhar
- Filtros: brilho, contraste, saturação, grayscale, blur, sepia

### Modo Anotação
- Highlight (retângulo semi-transparente)
- Seta de comentário
- Número de página/referência

### Modo Diagrama
- Snap-to-grid
- Alinhamento automático
- Conexões entre formas (arrows)
