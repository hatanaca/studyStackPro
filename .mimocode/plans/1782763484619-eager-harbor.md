# Plano: Restaurar funcionalidades quebradas sem desfazer correções

## Contexto

Agentes anteriores foram solicitados para criar testes e corrigir falhas de segurança/layout. Durante o processo, acabaram:
- **Removendo** o link de navegação para `/videos` (YouTube) da sidebar
- **Mudando** a posição da barra MiniPlayer de `bottom` para `top` no viewport
- **Adicionando** novas features (canvas, gaming/OP.GG, gráficos) com sidebar e rotas
- **Aplicando** correções de segurança, fixes de infra e melhorias de testes (tudo válido)

O objetivo é **manter todas as correções e features novas**, mas **restaurar o que foi quebrado**.

---

## Issues Encontrados

### Issue 1 (CRÍTICA) — Barra YouTube no topo em vez do rodapé
- **Arquivo**: `frontend/src/components/player/MiniPlayer.vue:273`
- **Problema**: CSS define `top: 0` para a barra colapsada, quando deveria ser `bottom: 0`
- **Impacto**: O player aparece cobrando o header/topo da página em vez de ficar no rodapé

### Issue 2 (CRÍTICA) — Link YouTube/Videos removido da sidebar
- **Arquivo**: `frontend/src/components/layout/AppSidebar.vue`
- **Problema**: O link de navegação para `/videos` (YouTube Search) foi removido durante a reorganização da sidebar
- **Impacto**: Rota existe, view existe, mas não há como navegar até ela pela UI

### Sem outros problemas
- Todas as rotas resolvem para componentes existentes
- Todos os imports estão corretos
- Todos os controllers PHP existem no disco
- As correções de segurança, fixes de infra e testes são todos legítimos e devem ser mantidos

## Plano de Correção

### Passo 1 — Corrigir posição da MiniPlayer (top → bottom)
**Arquivo**: `frontend/src/components/player/MiniPlayer.vue`

**Linha 273**, alterar:
```css
/* DE: */
.mini-player:not(.mini-player--expanded) { top: 0; left: 0; right: 0; }

/* PARA: */
.mini-player:not(.mini-player--expanded) { bottom: 0; left: 0; right: 0; }
```

### Passo 2 — Re-adicionar link YouTube/Videos na sidebar
**Arquivo**: `frontend/src/components/layout/AppSidebar.vue`

Adicionar um `<RouterLink to="/videos">` na sidebar, na posição correta (após "Tecnologias" e antes de "Canvas"), usando o mesmo padrão visual dos outros links. Incluir:
- SVG icon adequado (ícone de play/vídeo)
- Texto "Vídeos" ou "YouTube"
- `active-class="active"` com checagem `route.path.startsWith('/videos')`
